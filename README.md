# Калькулятор ипотеки

Онлайн-калькулятор ипотеки в BYN: график платежей, льготный период и досрочное погашение. Аннуитетный режим повторяет логику Беларусбанка.

## Что считает

- **Аннуитет** — равный платёж после льготы, пересчёт при досрочке.
- **Дифференцированный платёж** — тело кредита равными долями, проценты уменьшаются.
- Льготный период с отдельной ставкой: в эти месяцы платятся только проценты.
- Две ставки: на льготный год и после него.
- Досрочное погашение периодами (например 1–12, 13–24). Сумма сверх обязательного платежа.
- Итоги: обязательный платёж, проценты банку, фактический срок, экономия на процентах.

Ввод: сумма кредита, срок в месяцах, длительность льготы, ставки. Результат — сводка и помесячный график.

## Стек

React 19, TypeScript, Vite, styled-components.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Проверка продакшен-сборки: `npm run preview`.
